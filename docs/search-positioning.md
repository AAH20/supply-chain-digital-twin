# Search and hiring evidence

Exact keyword volume varies by region, date and platform and requires proprietary tooling. This repository maps broad category terms to implementation instead of inventing counts.

| Term | Evidence | Boundary |
|---|---|---|
| Artificial Intelligence / Machine Learning | Forecast competition and constrained decision engine | Deterministic baseline; no trained frontier model |
| Data Science / Predictive Analytics | Backtested forecast MAE | Synthetic history |
| Prescriptive Analytics | Ranked feasible disruption actions | No automatic execution |
| Supply Chain Management / Optimization | BOM propagation, service and economics | Implemented scenario engine |
| Inventory Management / Optimization | Availability, commitments and carrying cost | Single-period baseline |
| Demand Forecasting | Seasonal-naïve versus moving-average evaluation | Implemented baseline |
| Working Capital Optimization | Inventory cash and action cash modeled separately | Modeled, not realized |
| Digital Twin | Operational and financial state model | No physical twin claimed |
| Microsoft Fabric / Power BI | Target real-time and BI architecture | No Fabric capacity deployed |
| IoT / Predictive Maintenance | MQTT/OPC UA and asset signal integration path | Connector roadmap |
